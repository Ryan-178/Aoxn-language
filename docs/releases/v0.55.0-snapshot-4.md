# Aoxn v0.55.0-snapshot-4 发布说明

这是 Aoxn 0.55.0 的第四个预发布快照。编译器版本仍为 **0.55.0**，本快照不是
新的 minor 版本；它把 IDE 工作台重构与自举编译器、CLI、标准库这一批改动合并到
同一个发布点。

## 摘要

- **IDE**：工作台迁移到 ZCode v3.17.2 衍生的 Zai 设计系统，新增助手、终端、
  源码管理与预览面板。
- **自举语言**：`None` / `T | None`、`dict[V]`、函数指针和 `raise` / `try` /
  `except` 进入 `selfhost/`，在对照语料上与 Rust 发射器逐字节一致。
- **自举 CLI**：`run` 使用真实 argv 向量并传递子进程退出码；补齐选项、
  JSON 诊断、W001、`symbols`、`doctor` 和内容寻址运行缓存。
- **标准库**：新增 `stdlib/csv.ax`、`stdlib/random.ax`、`stdlib/socket.ax`，
  三者都不进入 `stdlib/stdlib.ax` 的自举关键路径。

## 主要变更

### IDE：ZCode 工作台重构

- 采用 ZCode v3.17.2 的 Zai 设计系统：Tailwind 4 token、shadcn/Radix 原语和
  `ai-elements` 会话/文件树外壳；Monaco 使用固定的 Zai Light/Dark 十六进制
  调色板，避免浏览器把 `color-mix()` 序列化成 Monaco 不接受的颜色值。
- 新外壳：标题栏、活动栏、可调整的资源管理器/编辑器/助手分栏，以及
  Output / Terminal / Source Control / Preview 底部面板和状态栏。
- 新面板与命令：OpenAI 兼容或 Anthropic 提供商驱动的助手对话
  (`ide_ai_chat`)、终端执行 (`ide_terminal_exec`)、Git 状态与 Monaco HEAD
  差异 (`ide_git_status` / `ide_git_diff`)，以及图片、PDF、Markdown 预览。
  编译器、包管理器、Monaco 语言服务和工作区桥接仍是唯一事实来源。
- 为 Git porcelain 解析和预览 MIME 映射增加纯 Rust 测试；补充 ZCode 与
  vercel/ai-elements 的第三方声明；文档链接检查器不再扫描被忽略的
  `.zcode-src` 参考树。

### 自举语言：v0.40 语言表面

- `None` / `T | None`：隐式放宽、`is None` / `is not None`、分支作用域收窄，
  以及提前返回后的收窄传播；混合数组字面量收窄到统一的元素类型。
- `dict[V]`：字符串键、单一值类型、共享堆句柄、带注解的空字面量、读写/
  `dict_del` / `dict_has` / `len`、插入顺序迭代，以及缺失键抛错。
- 函数指针：函数值、`fn(...) -> T` 注解、间接调用、`int` 与函数指针之间的
  `as` 转换和 `to_int`，以及包含函数指针返回值在内的完整 C 声明符。
- `raise` / `try` / `except`：字符串载荷、挂起错误槽、may-raise 不动点、
  逐语句传播、处理函数中的再次抛出，以及未捕获时的单次报告和退出码 1。
- 不使用这些特性的程序保持原有 C 文本逐字节不变。Rust 发射器的数组字面量
  提示同步修正：`[1, None, 3]` 现在得到 `[int | None; 3]`，不再触发
  let 绑定类型漂移断言。
- 词法分析器记录 token **起始**列和语句起始位置，使诊断、W001 与 `symbols`
  的行列形状在覆盖范围内与 Rust 编译器一致。

### 自举 CLI

- `run` 通过真实 argv 向量启动程序：Windows 使用 CRT `_spawnvp`，POSIX 使用
  `fork` / `execvp` / `waitpid`；Windows 参数按 CRT 规则引用，空参数、空格和
  特殊字符可原样到达子进程，不经过 shell。子进程退出码原样返回。
- 支持 `-o`、`--O0..--O3`、`-l` / `-L`、`--cpu`、`--backend c`、
  `--clang-arg`、`-g`、`--cc-warnings` 和 `--json`；环境变量
  `AOXN_CLANG` / `AOXN_CPU` / `AOXN_CLANG_ARGS` / `AOXN_CC_WARNINGS`
  提供默认值。
- 结构化 JSON 诊断写入 stderr，包含 stage / severity / code / file / line /
  col，并携带 W001 未使用局部变量警告；`check` 成功时也输出 warnings 数组。
- 实现 `symbols`（文本与 JSON）、`doctor`（含 `--no-smoke` 和 JSON）以及
  `version`。`run` 使用内容寻址缓存，键覆盖入口、全部传递导入、编译器可执行
  文件与代码生成选项；`AOXN_NO_CACHE` 和 `AOXN_CACHE_DIR` 生效。加载器通过
  `AOXN_STDLIB` / `AOXN_HOME/lib/stdlib` 解析 `stdlib` 和
  `stdlib/<module>`。

### 标准库模块

- **`stdlib/csv.ax`**：RFC 4180 解析与序列化。处理引号字段、逗号、CRLF/LF、
  嵌入换行、`""` 转义、空字段/空行和末尾无换行的最后一条记录；错误通过
  `err` / `msg` / `line` / `col` 值返回，不抛异常。测试在 Python 可用时与
  Python `csv` 模块逐字段、逐字节对比。
- **`stdlib/random.ax`**：确定性的非密码学 MINSTD。显式种子、
  `random_next` / `random_below` / `random_range`、`random_float` 以及返回
  状态的浮点区间函数（结果在 `.fval`）。拒绝采样避免取模偏差；非法边界返回
  `error=1` 且**不推进状态**。没有 CSPRNG API，也不声称安全随机。
- **`stdlib/socket.ax`**：阻塞 IPv4 TCP。`socket_init` / `connect` / `listen` /
  `accept` / `send_bytes` / `send_str` / `recv` / `recv_all` / `recv_line` /
  `close`，错误通过 `Sock{fd,err,msg}` 值返回。平台调用在各自函数内部用
  `target_os()` 守卫；Windows 的 C `int` 返回值经 `sk_i32` 处理零扩展；
  部分发送循环、`recv_all` 处理 EOF，默认监听**不**设置 `SO_REUSEADDR`。
  Windows 链接需要 `-l ws2_32`，POSIX 不需要额外库。

## 验证

Windows 最终验证于 2026-11-07 使用 clang 23.1.2 完成：

- **357 个根包测试 + 105 个包管理器测试 = 462 通过，0 失败/忽略**。
- 对照语料包含 19 个完整 C 文本比较输入、22 个拒绝用例和 3 个逐项钉住的已知
  差距；每个被接受的输入与 `src/codegen_c.rs` 比较完整 C 字节。
- 原有的跨阶段自举不动点继续独立通过；4 个 ABI 用例在 O0/O3 下执行；
  `selfhost/cli.ax` 的 stage-1 与 stage-2 生成 C 一致。
- 真实的 Windows 回环 socket 测试双向通过；random 的跨进程固定种子向量通过；
  Python `csv` 差分通过。
- IDE：64/64 前端测试、43 个 Rust 测试、`pnpm typecheck`、`pnpm build`、
  `pnpm audit`（无已知公告）和文档链接工具 11/11 通过。
- `cargo check --workspace --tests --target x86_64-unknown-linux-gnu` 通过，
  但这只是交叉检查，**不表示 Linux 原生运行已验证**。

## 已知边界

以下限制是明确记录而非近似实现：

- 自举 CLI 明确拒绝包管理器命令，绝不转发给 Rust CLI；CSS 资源、
  `--emit-assets` 和 `--tailwind` 不支持；命名空间导入和选择性导入未实现。
- `build` 命令的缓存仍未实现（只有 `run` 有缓存）；`doctor` 的完整行、
  导入符号的文件归属和精确诊断范围仍不完整。
- Linux 的 socket 与 CLI 代码路径已实现，但本轮只在 Windows 上实际运行；
  Linux 原生执行留待 CI 验证。
- `socket.ax` 只覆盖阻塞 IPv4 TCP：没有 DNS、UDP、IPv6、TLS 或超时；
  默认监听不设置 `SO_REUSEADDR`。
- `random.ax` 是确定性非密码学生成器，没有熵源；`csv.ax` 不提供方言参数或
  流式解析。
- 自举实现仍不支持默认参数、命名空间绑定和选择性导入；Rust CLI 仍是生产
  入口。

## 安装

Windows 发布资产为 `Aoxn-0.55.0-Setup.exe`。双击后安装到
`%LOCALAPPDATA%\aoxn`、写入 PATH 并运行 `aoxn doctor`；默认不下载任何东西。
clang 是外部前提；Windows 链接还需要 MSVC 兼容的 Build Tools。需要安装
clang 时可显式传入 `-InstallClang`。

```
aoxn run examples\hello.ax
aoxn doctor
```
